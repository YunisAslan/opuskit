# Media sources — Maison Vey

Photos found and picked by Claude through the Unsplash connector (2026-10-07), by the shot list in `recipe/media.md`,
to replace the build's temporary pictures file for file (no code changed). Every bottle, pipette and bench picture is
from one photographer's series in one perfume workshop (Fulvio Ciccolo), so the products share their glass, ground
and light; the places behind each scent and the harbour come from others. No brand names or logos. Unsplash licence:
free for commercial use, no attribution required — credited here anyway. Originals (up to 4000 px) in this folder;
graded copies, cropped to each asset key's exact size, in `public/media/`.
