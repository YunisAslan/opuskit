# Media sources — Ninth Row

The ten photos were found and picked by Claude through the Unsplash connector on 2026-10-09, by the shot list in `recipe/media.md`, and replace the temporary pictures file for file — same names, same pixel sizes, no code changed. Each was cropped to its slot's ratio around its subject, resized, and given one shared grade (gentle S-curve contrast, red +3.5 % / blue −7 % for tungsten warmth, warm lifted blacks, light monochrome film grain; JPEG q82 progressive) so they sit in the same light as the first-screen film; on `featuredWork-2` the film-stock brand name printed on the strip's edge was softened until unreadable. All are under the Unsplash License (free to use, no attribution required) and are credited here anyway; the first-screen film (`projector-original.mp4`) is the user's own, made with Google Flow.
