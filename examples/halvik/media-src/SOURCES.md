# Media sources — Halvik

All files are under the Unsplash License, downloaded at Original size on 2026-10-02 with the Unsplash connector, picked
by Claude at the user's request (docs/plan-for-fit.md §7). Each was checked for readable real brand names or logos.
Dropped for that reason: every headphone series tried first (Sony, Huawei, Sennheiser, Beats, Apple), keyboard shots
with a toy Ferrari, an Apple Watch or "AKAI" in view.

Originals here are untouched. `public/media/` holds them resized to at most 2400 px on the long side (JPEG q82).
**Retouched:** in `hero`, `product`, `product-2` and `row-1` the Esc keycap carries a small fox mark (the keycap set's
logo); it was removed with ffmpeg `delogo` before resizing, so the key reads blank.
