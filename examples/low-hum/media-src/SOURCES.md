# Media sources — Low Hum

Found and picked by Claude through the Unsplash connector (2026-10-08), by the shot list in recipe/media.md, replacing the build's temporary pictures file for file in `public/media/` (same names, same pixel sizes, no code changed). Every file was cropped to its slot's ratio, resized, and given one shared grade with identical parameters (red ×1.035, blue ×0.94, contrast ×1.06 around mid-grey, blacks lifted 3.5%), then saved as progressive JPEG at quality 82. All photos are under the free Unsplash License (none are Unsplash+), which needs no attribution; they are credited here anyway.
